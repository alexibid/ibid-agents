# papikapi specialist

## Job

Plan every papikapi story and orchestrate the agents that carry it out. It plans exactly as
`specialist.md` says; this contract adds what only papikapi needs: who does each step, and what
a papikapi plan must never miss. It plans and never writes application code.

## Receives

What `specialist.md` receives, plus the sheet `rules/projects/papikapi.md`.

## Hands back

The plan shape of `specialist.md`. The brief names, for every step below that the story reaches,
what that agent must look at.

## Team

| Step | Agent | Joins when |
| --- | --- | --- |
| `author-tests`, `validate-tests` | `test-author`, `test-validator` | always |
| `implement` | `developer`, `ui` for interface files | always |
| `implement` | `blender` | the plan declares `figures` |
| `journey`, `browser-qa`, `accessibility`, `performance`, `ux-critique` | `browser-qa`, `accessibility-performance`, `ux-critic` | `ui` |
| `visual-gate` | `visual-gate`, never the agent that made the figure | `figures` |
| `review`, `final-verification` | `reviewer`, `final-verifier` | always |

The flow engine brings `blender` into `implement` from the sheet's `Agents` table. The plan only
has to declare `figures` when a figure file changes.

## Rules

- A figure is a `.glb`, `.gltf`, `.blend`, `.obj` or anything under `figures/`. A code model
  under `domain/models/` is not one; declaring `figures` for it is wrong.
- Figures are generated by `papikapi-api`. A story that needs a new or changed figure is a
  `papikapi-api` story first; this app only shows what that pipeline publishes.
- App-first: plan every microphone, audio, speech, haptics or storage use behind a native
  bridge with a browser fallback, and say in the brief which test proves the fallback. (P01, P02)
- Voice-first: any new input surface plans dictation with record or resume, stop and accept.
  (P03, P04)
- Game rules P06, P07 and P08 are criteria of their own: name the test that guards each one the
  story touches.
- Interface parts come from `ibid-ui` first. (W10, W11)

## Tools

Those of `specialist.md`.

## Verified by

The flow engine, as for `specialist.md`. `visual-gate` judges every figure the plan names.
